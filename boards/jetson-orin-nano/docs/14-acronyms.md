# 14 · Acronyms and names

[Docs](README.md) › **14 · Acronyms**

Definitions are as NVIDIA's Developer Guide (R36.4.3) uses them, or as the file names in the package show. Where we only know a
word from a file name, the entry says so.

## Chips and processors

| Term | Meaning |
| --- | --- |
| **Orin / T234 / `tegra234`** | the SoC family. `tegra234-…` is the prefix of every Orin device tree and firmware file |
| **P3767** | the module (Orin NX and Orin Nano) |
| **P3768** | the Orin Nano Developer Kit carrier board |
| **P3701 / P3737** | the AGX Orin module / its developer-kit carrier (not covered here) |
| **CCPLEX** | the CPU complex: the Arm cores that run UEFI, the kernel and your programs |
| **BPMP** | boot and power management processor: runs the BootROM and MB1, later manages clocks, resets and power. Firmware: `A_bpmp-fw` |
| **PSC** | platform security controller: holds keys (PSC ROM), authenticates the first boot stages. Firmware: `psc_bl1`, `psc-fw` |
| **SPE** | sensor processing engine, a small auxiliary core; firmware `spe_t234.bin`, source `spe-freertos-bsp` (FreeRTOS) |
| **RCE** | camera real-time engine; firmware `camera-rtcpu-t234-rce.img` (the "camera RTCPU" in the file name) |
| **DCE** | display control engine; firmware `display-t234-dce.bin` |
| **APE / ADSP** | audio processing engine; firmware `adsp-fw.bin` |
| **PVA** | programmable vision accelerator; firmware `nvpva_020.fw` |
| **MCE** | CPU-side firmware (`mts_mce` partition, file `mce_flash_o10_cr_prod.bin`). We only know the name |
| **TSEC · NVDEC · XUSB** | security engine · video decoder · USB 3 controller firmware partitions |
| **GPU / `nvgpu`** | the Ampere GPU and its driver (`nvgpu` module, source `source/nvgpu`) |

## Boot software

| Term | Meaning |
| --- | --- |
| **BootROM (BR)** | code in the chip's mask ROM; the first thing that runs; loads the first stages from QSPI-NOR, or waits on USB in recovery mode |
| **BR-BCT** | BootROM boot configuration table |
| **BCT** | boot configuration table: platform configuration expressed as device-tree source (`bootloader/generic/BCT/*.dtsi`) |
| **MB1-BCT · Memory BCT · MB2-BCT** | configuration for MB1 (pinmux, GPIO, PMIC, firewalls), for SDRAM initialisation, and for MB2 |
| **MB1 / MB2** | Microboot 1 / 2: NVIDIA's first and second-stage bootloaders |
| **MB2 applet** | the variant of MB2 that runs on the BPMP to identify the device for the flashing host |
| **PSC-BL1** | the first software that runs on the PSC |
| **CPUBL** | CPU bootloader: here, UEFI |
| **UEFI / EDK2** | the firmware standard / its open-source implementation. NVIDIA's version: `NVIDIA/edk2-nvidia` |
| **L4TLauncher** | UEFI's default OS loader (`BOOTAA64.efi`); reads `extlinux.conf` or the kernel partitions |
| **`extlinux.conf`** | the boot menu file in `/boot/extlinux/` of the root filesystem |
| **L4T** | Linux for Tegra: NVIDIA's name for this software release (Jetson Linux) |
| **OP-TEE / TOS** | the open-source trusted execution environment and "trusted OS" image in `A_secure-os` |
| **ATF / TF-A** | Arm Trusted Firmware, which OP-TEE runs on in NVIDIA's `tos-optee_t234.img` |
| **ESP** | EFI system partition: FAT filesystem holding `EFI\BOOT\BOOTAA64.efi` |
| **SDRAM** | the module's main memory |
| **EKS** | the `A_eks` partition (encrypted key store: the name suggests secure storage; see NVIDIA's *Secure Boot*) |
| **SC7 / WB0** | the deep-sleep state and the firmware used to resume from it (`A_sc7`) |

## Flashing

| Term | Meaning |
| --- | --- |
| **QSPI-NOR** | the module's 64 MiB boot flash |
| **RCM · Force Recovery Mode** | the BootROM's USB mode: waits for a host to load code |
| **`initrd` flash** | flashing with a small Linux (the *initrd*) booted over USB on the board |
| **flash package** | the images and initrd generated by `l4t_initrd_flash.sh --no-flash` |
| **tegraflash / `tegraflash.py`** | NVIDIA's lower-level flashing driver, called by `flash.sh` |
| **board spec / `.conf`** | the `Linux_for_Tegra/<board>.conf` shell files |
| **partition layout / XML** | `flash_t234_*.xml`: partitions, sizes, which file goes where |
| **APP · UDA · ESP** | the root filesystem partition · "user data area" · EFI system partition |
| **slot A / slot B** | the two copies of the boot firmware (and, optionally, of the rootfs) |
| **capsule** | a UEFI firmware update payload applied to the non-current slot |
| **SKU · FAB · board ID** | module variant, hardware revision and board identity, as the tool reads them (`BOARDSKU`, `FAB`, `BOARDID`) |
| **PKC · SBK** | public-key and secret-boot-key fuses used for secure boot; irreversible once burned |
| **NFS** | the network file system through which the board reads the flash package |

## Linux and userland

| Term | Meaning |
| --- | --- |
| **`nvpmodel`** | selects a power mode (`/etc/nvpmodel/*.conf`) |
| **`jetson_clocks`** | pins clocks at their maximum for the current mode |
| **`tegrastats`** | live utilisation, power and temperature |
| **`nvbootctrl`** | shows and sets the boot firmware slot |
| **`jetson-io`** | configures 40-pin header functions through a device-tree overlay |
| **OOT modules** | out-of-tree kernel modules: NVIDIA's drivers built outside the kernel tree |
| **DTB / DTBO / DTS** | device tree blob / overlay / source |
| **JetPack** | NVIDIA's name for the software stack on top of Jetson Linux (CUDA, cuDNN, TensorRT …). JetPack 6.2 = Jetson Linux R36.4.3 |
